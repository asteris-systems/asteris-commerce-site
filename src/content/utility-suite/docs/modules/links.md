# Configure Asteris Links

For the marketing overview of this module, see [/modules/links](/asteris-utility-suite/modules/links/). This page covers the practical setup — Quickstart, every settings field, common workflows (bulk import, category-grouped reports, anchor-rel attributes), and the developer surface.

Asteris Links is a **branded affiliate link cloaker + click tracker**. Turn `https://amazon.com/dp/B08K9V7DZJ?tag=yourshop-20&linkCode=osi&th=1&psc=1` into `https://yoursite.com/go/wireless-mouse`. Cleaner. Trackable. Reorganisable. Replaces Pretty Links and ThirstyAffiliates with no licence cost on top of Asteris.

---

## Quickstart (3 minutes)

### 1. Decide on the URL prefix

The default cloaked URL prefix is `/go/`. So `https://yoursite.com/go/wireless-mouse` redirects to whatever destination you set.

If you don't like `/go/` (some affiliate networks prefer `/recommends/`, some bloggers use `/r/`), change it now:

**WP Admin → ★ Asteris → 🔗 Asteris Links → ⚙ Settings tab**

- **URL prefix** — default `go`. Change to anything that's a valid URL slug (alphanumeric + hyphens, no slashes). Save.

After saving, all existing cloaked URLs are accessible at the new prefix. **Flush permalinks once** (Settings → Permalinks → Save Changes — no edits needed; the act of saving rewrites the rewrite rules).

### 2. Create your first link

**★ Asteris → 🔗 Asteris Links → + Add new link**

- **Title** — what you'll see in the admin list. Not visible to visitors. Example: *"Amazon — Logitech MX Master 3"*
- **Slug** — the path after your URL prefix. Example: `mx-master-3` → final URL becomes `https://yoursite.com/go/mx-master-3`
- **Destination URL** — paste the long affiliate URL with all its tracking params
- **Redirect type** — 301 (permanent) by default. See [Redirect type](#redirect-type-301-vs-302-vs-307) below for the trade-offs.
- **Nofollow** — checked by default. Adds `rel="nofollow"` to anchors generated by the shortcode. Recommended for affiliate links per Google's guidelines.
- **Sponsored** — checked by default. Adds `rel="sponsored"` to anchors. Required by Google's link spam policy for paid links.

Click **Save link**.

### 3. Use the link in your content

You have three options. Pick whichever fits your workflow:

**Option A — Plain link to the cloaked URL:**

```html
<a href="https://yoursite.com/go/mx-master-3">Logitech MX Master 3</a>
```

Manually add the rel attributes if you want them. The redirect still tracks the click.

**Option B — Use the shortcode** (automatically renders the configured rel attributes):

```
[asteris_link slug="mx-master-3"]Logitech MX Master 3[/asteris_link]
```

Gives you `<a href="https://yoursite.com/go/mx-master-3" rel="nofollow sponsored noopener" target="_blank">Logitech MX Master 3</a>` rendered into your post.

**Option C — Bulk-replace existing URLs** (next workflow).

### 4. Done

Visitors clicking the cloaked URL get a 301 redirect to the affiliate destination. Click counts and last-hit timestamps update on every redirect. **★ Asteris → 🔗 Asteris Links** lists every link with its hit count, last-clicked time, and a Copy URL button.

## Common workflows

### Bulk-import affiliate links from a CSV

If you're switching from Pretty Links or ThirstyAffiliates — or have a spreadsheet of links from your affiliate dashboard — the CSV importer handles hundreds of links at once.

**★ Asteris → 🔗 Asteris Links → 📥 Import CSV tab**

**CSV format** (header row required):

```csv
title,slug,destination,redirect_type,nofollow,sponsored,category
Amazon — MX Master 3,mx-master-3,https://amazon.com/dp/B08K9V7DZJ?tag=yourshop-20,301,1,1,Electronics
Bluehost — Starter Plan,bluehost-starter,https://www.bluehost.com/track/yourshop/,301,1,1,Hosting
ConvertKit — Annual,convertkit-annual,https://convertkit.com/?lmref=YOURCODE,302,1,1,Email tools
```

- `title`, `slug`, `destination` are required
- `redirect_type` accepts `301`, `302`, or `307`. Defaults to 301.
- `nofollow` and `sponsored` accept `1` / `0`. Default to 1.
- `category` is optional; if present, the category is auto-created if it doesn't exist
- Duplicate slugs in the CSV are skipped (existing link with that slug wins)

Click **Upload CSV**. The importer processes inline and reports `Imported: N · Skipped: M · Errors: E`. Errors include malformed URLs, invalid slug characters, and any row missing one of the three required columns.

Existing click counts are preserved on existing slugs — re-importing the same CSV doesn't zero out your analytics.

### Organise links by category

Categories let you slice the click-report table ("show me hosting links only", "show me Q4 promotion links only") and group related affiliate programs.

**★ Asteris → 🔗 Asteris Links → 🗂 Categories tab**

- Add categories (e.g. "Hosting", "Email tools", "Books").
- When creating or editing a link, pick a category from the dropdown (or leave uncategorised).
- The main links list table shows a Category column; click any header to sort.

You can also bulk-assign categories with the **Edit selected → Set category** dropdown in the list-table actions.

### Mark a link `nofollow` + `sponsored` (Google compliance)

Google's link spam policy ([developers.google.com/search/blog/2019/09/evolving-nofollow-new-ways-to-identify](https://developers.google.com/search/blog/2019/09/evolving-nofollow-new-ways-to-identify)) requires paid links to carry `rel="sponsored"` (since 2020). Affiliate links count as paid links — even if you're not paid directly, you receive commission.

Both flags are **checked by default** on new links. The shortcode (`[asteris_link]`) renders the rel attributes; plain `<a href>` tags pointing at the cloaked URL do NOT carry the rel attributes (visitors hit the redirect chain regardless, but Google's crawler sees the anchor on your page).

For SEO purposes: **always use the shortcode for affiliate links** so the rel attributes ship in the rendered HTML.

### Track which links convert (click-report)

**★ Asteris → 🔗 Asteris Links** — the main list table.

Each link row shows:

- **Title** + **Slug**
- **Destination** (truncated to 40 chars with a hover-tooltip showing the full URL)
- **Category**
- **Total hits** — lifetime click count
- **Last hit** — relative timestamp (e.g. "3 hours ago"). Empty if never clicked.
- **Status** — Active / Disabled
- Actions — Edit, Disable, Delete, **📋 Copy URL** (copies `https://yoursite.com/go/slug` to clipboard)

Sort by clicking any column header. Filter by category from the dropdown above the table. The "Last hit" sort is useful for identifying dead links — anything that hasn't fired in 90+ days probably has a broken destination.

To see clicks **per day** (not just lifetime totals), enable the Insights module — Insights records every `asteris_link_hit` event with the slug as a property. The Insights dashboard's **Custom events** tile breaks it down by link slug.

### Disable a link without deleting it

You might want to pause a link without losing its historical click data (e.g. a seasonal promotion ends but you'll bring it back next year).

In the list table → click **Disable** on the link row. The redirect now returns a `410 Gone` response. Click counts stop. The link stays in the database with all historical data intact.

Re-enable the same way — click **Enable**. Visitors clicking the cloaked URL after re-enable get the normal redirect again.

### Change a destination URL globally

Affiliate URLs change — programs migrate to new tracking domains, tags get rotated. With cloaked links, you change the destination ONCE in **★ Asteris → 🔗 Asteris Links → Edit** and every cloaked URL pointing at it now redirects to the new destination. Every link in your old posts, social posts, email campaigns — instantly updated.

This is the #1 reason to use cloaking even if you don't care about pretty URLs.

### Redirect type — 301 vs 302 vs 307

- **301 (Moved Permanently)** — default. Browsers and proxies cache the redirect aggressively. Best for stable destinations.
- **302 (Found, temporary)** — browsers don't cache. Use when the destination might change soon, or for A/B-test campaigns where you want every visitor to hit your server (and re-evaluate the destination).
- **307 (Temporary Redirect, method-preserving)** — like 302 but preserves POST/PUT/DELETE. Almost never needed for affiliate links. Use only if your destination accepts non-GET methods.

Asteris stores the redirect type per link, so you can mix them within the same site. Change at any time — clear the visitor's browser cache for the change to take effect for previously-cached redirects.

## Settings reference

Every field on **★ Asteris → 🔗 Asteris Links → ⚙ Settings tab**, in order.

### URL prefix

- Default: `go`
- Validation: alphanumeric + hyphens, no slashes, 1–32 chars
- Result: all cloaked URLs live at `https://yoursite.com/{prefix}/{slug}`

After changing, **flush permalinks** by visiting Settings → Permalinks and clicking Save Changes (no edits needed). Until you do, the new prefix returns 404s.

### Default redirect type

- Choices: `301`, `302`, `307`
- Default: `301`
- Applies to new links only. Existing links keep their per-link redirect type setting.

### Default nofollow

- Default: checked
- Applies to new links only. Shortcode-rendered anchors include `rel="nofollow"`.

### Default sponsored

- Default: checked
- Applies to new links only. Shortcode-rendered anchors include `rel="sponsored"`.

### Default target

- Choices: `_blank` (open in new tab), `_self` (same tab)
- Default: `_blank`
- Applied to shortcode-rendered anchors. When `_blank`, `rel="noopener"` is added automatically to prevent the reverse-tabnabbing security issue.

### Track logged-in admins

- Default: unchecked
- When unchecked, redirects by users with `manage_options` are excluded from click counts. Keeps your QA clicks from polluting analytics.

## Developer surface

### Shortcode

```
[asteris_link slug="mx-master-3"]Display text here[/asteris_link]
```

Renders:

```html
<a href="https://yoursite.com/go/mx-master-3" rel="nofollow sponsored noopener" target="_blank">Display text here</a>
```

The rel + target attributes come from the link's own settings (which inherit from defaults at creation time). The display text is the shortcode body — falls back to the link's title if the body is empty.

### Custom post type

Each link is stored as `asteris_link` post-type:

- `post_title` — the title
- `post_name` — the slug
- `post_meta._asteris_link_destination` — the destination URL
- `post_meta._asteris_link_redirect_type` — 301 / 302 / 307
- `post_meta._asteris_link_nofollow` — `1` / `0`
- `post_meta._asteris_link_sponsored` — `1` / `0`
- `post_meta._asteris_link_hits` — lifetime click count (integer)
- `post_meta._asteris_link_last_hit` — UTC datetime string

Category taxonomy is `asteris_link_cat`.

You can query links via `WP_Query`:

```php
$links = new WP_Query( [
    'post_type'      => 'asteris_link',
    'tax_query'      => [
        [
            'taxonomy' => 'asteris_link_cat',
            'field'    => 'slug',
            'terms'    => [ 'hosting' ],
        ],
    ],
    'posts_per_page' => -1,
] );
```

### Action — hooked on every click

```php
add_action( 'asteris_wp_link_clicked', function( int $link_id, string $slug, string $destination ): void {
    // your custom logging / analytics
}, 10, 3 );
```

Fires after the click counter is incremented but BEFORE the HTTP redirect is sent. Use it to write to your own analytics, fire a webhook to a CRM, or trigger an email digest.

### REST endpoints

- `GET /wp-json/asteris-wp/v1/links` — list all links (auth: `edit_posts`). Supports `?category=hosting`, `?orderby=hits`, `?per_page=50`.
- `POST /wp-json/asteris-wp/v1/links` — create. Body: `title`, `slug`, `destination`, `redirect_type`, `nofollow`, `sponsored`, `category`.
- `PUT /wp-json/asteris-wp/v1/links/{id}` — update.
- `DELETE /wp-json/asteris-wp/v1/links/{id}` — delete.

Standard WP REST nonce required (`X-WP-Nonce` header).

## Troubleshooting

### Cloaked URLs return 404

The most common cause is stale rewrite rules. After changing the URL prefix OR after a fresh install:

**Fix:** **Settings → Permalinks → Save Changes** (no edits needed — the act of saving rewrites the rules).

If that doesn't fix it, check that your `.htaccess` (Apache) or nginx config isn't intercepting `/go/*` requests before they reach WordPress. Some hosts block paths that look like CGI / proxy patterns.

### Click counts don't update

Two possible causes:

1. **You're a logged-in admin and "Track logged-in admins" is unchecked.** Open the cloaked URL in incognito (or log out) and the counter increments.
2. **An aggressive caching layer is serving the redirect** before WordPress sees it. Some CDN configurations cache 301s. Either exclude `/go/*` from the cache OR switch the link to a 302 redirect so the CDN doesn't cache.

### Imported CSV creates duplicate slugs as numbered variants

If the CSV contains a slug that already exists, the importer skips the row by default. If you want to OVERWRITE, tick **Update existing on slug match** before uploading. Be careful — overwriting resets click counts unless the **Preserve hit counts** checkbox is also ticked.

### Shortcode renders nothing in the editor preview

The Block Editor's shortcode block renders shortcodes server-side, so the live preview shows the actual anchor. If you see nothing rendered:

1. Check the slug is correct — typos return an empty string.
2. Check the link's status — disabled links render an empty string.

If the slug is right and the status is Active, hard-refresh the editor. If still empty, check the browser console for a REST error fetching the link's data.
