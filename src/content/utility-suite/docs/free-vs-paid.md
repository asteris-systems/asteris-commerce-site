# Asteris Utility Suite Free vs paid — what's the difference

Asteris Utility Suite Free includes **5 of the 12 modules**. Paid tiers (Starter / Pro / Agency) include **all 12**. The 5 free modules are "lite" versions of their paid counterparts.

---

## The 5 free modules and what each version covers

**Image Optimisation (lite)**
Free: JPEG / PNG compression. WebP conversion. Bulk-optimise existing media library. On-upload auto-optimise. Before/after comparison.
Paid adds: AVIF conversion. CDN integration (Cloudflare, Bunny, generic). Lazy-loading rules per post-type. EXIF stripping. Retina (2x) generation.

**Analytics + Pixels (lite)**
Free: GA4. Google Tag Manager container. Meta Pixel base. Basic event firing.
Paid adds: Google Ads conversions. Meta Conversions API. TikTok Pixel + Events API. Pinterest Tag. LinkedIn Insight. Microsoft Clarity. Consent Mode v2. Custom event recipes.

**Activity Log (lite — capture-only)**
Free: 100+ event types captured (logins, post edits, plugin/theme changes, user changes, settings). Filtering, search, CSV export.
Paid adds: per-event Asteris Undo (revert any logged change). Site Health tab. Debug snapshot ZIP. Temp support user provisioning.

**SMTP (lite — generic SMTP only)**
Free: Generic SMTP (any host/port/auth). Connection test. Basic delivery status.
Paid adds: Gmail OAuth, Microsoft 365 OAuth, SendGrid, Mailgun, Amazon SES native APIs. Full email logs with body capture. Resend (single + bulk). CSV export. Retention cron. Deliverability alerts. AES-256-CBC encrypted credentials at rest.

**Accessibility scanner (lite)**
Free: On-save WCAG 2.1 AA scan of any post / page. 13 checks. In-editor metabox with issues + line numbers.
Paid adds: Site-wide audit dashboard. Worst-offenders report. EAA-compliant accessibility statement generator. Scheduled site-wide rescans. REST endpoint for CI integration.

## The 5 modules only in paid tiers

- **Security + Login + 2FA** — brute-force protection, TOTP + WebAuthn passkey 2FA, file-change monitoring, IP geofence
- **SEO + AI Suite** — titles, schema, sitemaps, redirects, AI content tools, llms.txt, IndexNow, AI bot blocker, one-click Yoast importer
- **Performance** — caching, fetchpriority on LCP, Speculation Rules, Early Hints, field-data Core Web Vitals monitor
- **Forms** — 20 field types, conditional logic, multi-step, 5 integrations, three-layer anti-spam
- **Backups + Migration** — scheduled backups to S3 / B2 / R2 / Wasabi / SFTP / local, AES-256, one-click restore, cross-site migration
