# Asteris Utility Suite Free

**Asteris Utility Suite Free is five real WordPress modules in one plugin, free forever on WordPress.org.** No credit card. No upsell wall. No time-limited trial. GPL-2.0+ licensed. Unlimited sites.

**What's included:**

1. **Image Optimisation (lite)** — JPEG/PNG compression, WebP conversion, bulk-optimise, **EXIF stripping**
2. **Analytics + Pixels (lite)** — GA4, Google Tag Manager, Meta Pixel base, basic events, **Google Consent Mode v2**
3. **Activity Log (lite)** — capture-only audit log of 100+ event types
4. **SMTP (lite)** — generic SMTP, **Gmail OAuth, Microsoft 365 OAuth**, **basic email logs**, encrypted credentials
5. **Accessibility scanner (lite)** — WCAG 2.1 AA on-save scan with 13 checks
6. **Content locale setting** (sitewide) — pick `en-US`, `en-GB`, `en-AU`, `en-CA`, `en-IE`, `en-NZ`, `en-IN`, or `en-ZA` once; all plugin-generated text (default email templates, default form messages, accessibility statement boilerplate) uses that variant

Asteris Utility Suite Free is the same codebase as the paid version, with five modules unlocked and the rest gated behind a licence. The free modules aren't crippled marketing demos — they're the same engineering everyone else uses; you just get a subset of the suite.

If you outgrow the free set, upgrade in WP Admin. If you don't, keep running the free version forever.

## The 5 modules

### Image Optimisation — lite

Bulk-optimise existing images. Convert to WebP for browsers that support it. Compress new uploads automatically. Strip EXIF metadata for privacy + file-size savings.

**Free includes:** bulk JPEG/PNG compression, on-upload optimisation, WebP conversion, EXIF stripping, before/after comparison.

**Paid unlocks:** AVIF conversion, CDN integration (Cloudflare Polish / Bunny / Cloudinary / ImageKit), image lazy-loading rules per post-type, retina (2x) generation.

### Analytics + Pixels — lite

GA4, Google Tag Manager, Meta Pixel — installed correctly without a snippet plugin and EU-compliant out of the box thanks to **Google Consent Mode v2** auto-wiring.

**Free includes:** GA4, GTM container, Meta Pixel base, basic event firing, **Google Consent Mode v2** (auto-wires with Cookiebot / OneTrust / Iubenda / CookieYes / Complianz).

**Paid unlocks:** Google Ads conversions, Meta Conversions API (server-side), TikTok Pixel + Events API, Pinterest Tag, LinkedIn Insight, Microsoft Clarity, enhanced ecommerce events, custom event recipes.

### Activity Log — lite (capture-only)

Records what changed on the site, who changed it, and when. Free version captures and displays the log; the paid version adds one-click undo + temp support user provisioning.

**Free includes:** activity capture (logins, post edits, plugin/theme changes, user changes, settings changes), filtering, CSV export.

**Paid unlocks:** per-event Asteris Undo (revert any logged change), Site Health tab integration, debug snapshot ZIP for support, temp support user provisioning.

### SMTP — basic

Send WordPress email through a real SMTP server, including **Gmail and Microsoft 365 with full OAuth 2.0**. Plus basic email logs so you can see what got sent.

**Free includes:** generic SMTP, **Gmail OAuth, Microsoft 365 OAuth**, connection test, **basic email logs** (recipient, subject, date, status — no body capture), AES-256-CBC encrypted credentials at rest.

**Paid unlocks:** SendGrid / Mailgun / Amazon SES native APIs, **full email logs with body capture** (HTML + plain text), one-click resend, bulk resend, CSV export, retention cron, deliverability alerts, DNS SPF/DKIM/DMARC check, bounce + complaint webhook auto-suppression.

### Accessibility scanner — lite

Scans posts and pages against WCAG 2.1 AA criteria. Helps you find the easy wins (alt text missing, low colour contrast, empty buttons, headings out of order).

**Free includes:** on-save scan of any post/page, 13 WCAG checks, in-editor metabox with issues + line numbers.

**Paid unlocks:** site-wide audit dashboard, worst-offenders report, **EAA-compliant accessibility statement generator with locale-aware templates** (US ADA / UK Equality Act / EU EAA / AU DDA / CA AODA / NZ / IE / IN / ZA), scheduled rescans, REST endpoint for CI integration.

### Content locale setting

Pick your site's English variant once — `en-US`, `en-GB`, `en-AU`, `en-CA`, `en-IE`, `en-NZ`, `en-IN`, or `en-ZA`. Every default string the plugin emits (form validation messages, email template defaults, accessibility statement boilerplate, llms.txt connecting prose) uses that variant. None of the competing all-in-one plugins ship this — most assume US English everywhere.

**Free includes:** the locale picker + 8 English variants for default strings.

**Paid unlocks:** AI Suite content generation (briefs, drafts, meta descriptions) also respects the configured locale, so AI output matches your site's voice automatically.

## Install

1. In WP Admin, go to **Plugins → Add New**.
2. Search for *Asteris Utility Suite*.
3. Click Install, then Activate.
4. Visit **Asteris** in the admin menu — modules are off by default; turn on what you want.

No account. No email signup. No "verify your installation" step.
